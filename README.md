# 沪深300多因子选股策略

基于 **LightGBM + Ridge + K-means 聚类** 的沪深300多因子选股策略，带 Walk-Forward 验证和向量化回测。

> 核心问题：非线性模型（LightGBM）能否在真实交易成本下跑赢线性模型（Ridge）？

## 数据说明

- **标的**：沪深300成分股（174只，过滤28只数据不足的股票后）
- **时间**：2018-01-01 至 2022-12-31（1215个交易日）
- **来源**：baostock 开源数据
- **因子**：
  - PE（市盈率，取自财报）
  - 20日动量（Momentum_20）
  - 60日波动率（Vol_60）

## 方法框架

```
┌─────────────────────────────────────────────────────────┐
│  1. 数据加载 & 清洗                                       │
│     - baostock 获取日线数据                                │
│     - 过滤 <60% 交易日覆盖的股票（去除新股/退市干扰）       │
├─────────────────────────────────────────────────────────┤
│  2. 因子计算 & IC 分析                                    │
│     - MAD 去极值 + z-score 标准化                         │
│     - 日度 IC / IC_IR / 分年度 IC                        │
│     - 保存全部分析结果至 CSV                              │
├─────────────────────────────────────────────────────────┤
│  3. K-means 聚类                                         │
│     - 在因子空间聚类（4簇），选最优簇                      │
│     - 聚类标签作为额外特征                                │
├─────────────────────────────────────────────────────────┤
│  4. Walk-Forward 滚动验证                                 │
│     - LightGBM（非线性） vs Ridge（线性基线）              │
│     - 滚动窗口：24个月训练 → 6个月验证                    │

├─────────────────────────────────────────────────────────┤
│  5. 向量化回测                                            │

```

## 回测结果（2018-2022）

| 指标 | LightGBM | Ridge |
|------|:-------:|:-----:|
| 年化收益 | **21.26%** | 20.74% |
| 夏普比率 | **0.84** | 0.74 |
| 最大回撤 | **-24.49%** | -31.46% |
| 总收益 | **153.96%** | 148.76% |
| 预测IC | -0.0098 | -0.0037 |

### 关键发现

1. **非线性模型（LightGBM）** 在年化收益和风控上都优于 Ridge：
   - 夏普比率高出 13.5%（0.84 vs 0.74）
   - 最大回撤从 -31.46% 缩至 -24.49%，回撤控制显著改善

2. **因子IC偏弱**：三个因子的IC表现一般（平均IC在 -2%～-0.5%），说明传统基本面因子的预测能力有限

3. **特征重要性**：波动率因子贡献最大（LGB权重 982），其次是 PE（839）和动量（786）

4. **Walk-Forward 验证**：11个滚动窗口的结果相对稳定，模型未出现明显过拟合
